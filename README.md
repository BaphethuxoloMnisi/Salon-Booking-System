# Salon-Booking-System
# Maison Orchid - Salon Booking System

A modern and responsive salon booking system designed to provide customers with a simple way to explore salon services and schedule appointments online.

## Live Website

[Maison Orchid](https://salonbookingapplication.netlify.app/)

## Overview

Maison Orchid provides an online interface where customers can:

* View available salon services
* Browse the salon gallery
* Select a service
* Choose an appointment date
* Select an available time slot
* Enter their personal details
* Add optional booking notes
* Confirm their appointment
* Download a booking receipt

The system also includes a separate staff administration page for managing salon bookings.

## Features

### Customer Features

* Modern salon landing page
* Service listings
* Salon gallery
* Appointment date selection
* Available time-slot selection
* Customer information form
* Phone and email details
* Optional booking notes
* Booking confirmation
* Downloadable booking receipt

### Staff Features

* Staff/Admin access page
* Booking management interface
* View and manage customer bookings
* Link back to the main salon website

## Technologies Used

* HTML5 - Website structure
* CSS3 - Styling and responsive layout
* JavaScript - Booking functionality and application logic
* Google Fonts - Bodoni Moda and Figtree typography
* Local browser storage - Client-side booking data management

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/BaphethuxoloMnisi/Salon-Booking-System.git
```

### Navigate to the Project

```bash
cd Salon-Booking-System
```

### Run the Website

The project is a frontend web application and does not require a backend server for the basic version.

Open `index.html` in a web browser.

For development, the project can also be opened using Visual Studio Code with the Live Server extension.
